# AutoRia Monitor

Telegram-бот, який стежить за новими оголошеннями на [AUTO.RIA](https://auto.ria.com)
і одразу надсилає їх у Telegram: фото авто, ціна, пробіг, місто і кнопка на
оголошення.

- Пошуків скільки завгодно, кожен налаштовується звичайним фільтром на сайті.
- Перевірка кожні 5 хвилин, 24/7 на сервері.
- Кожне авто приходить один раз, навіть якщо підходить під кілька пошуків.
- Якщо сайт або інтернет недоступні, бот пояснює причину простими словами і
  повідомляє, коли все знову працює.
- Керування тільки кнопками в Telegram, файли редагувати не треба.

## Як користуватися

### Додати пошук

1. Відкрийте auto.ria.com **у браузері** (на телефоні теж; з додатка AUTO.RIA
   поділитися можна тільки окремим авто, а не пошуком).
2. Налаштуйте фільтр: марка, модель, рік, ціна, регіон тощо.
3. Натисніть «Показать предложения» і скопіюйте адресу сторінки.
4. Надішліть посилання боту.
5. Бот перевірить посилання і запропонує назву, наприклад
   «💾 Зберегти як «BMW 3 Series GT 2013–2023»». Можна натиснути кнопку або
   написати свою назву.

Сортування в фільтрі не важливе: бот сам ставить «спочатку нові». Те, що вже
є на сайті в момент додавання, бот запам'ятовує і не надсилає, тож приходять
тільки нові оголошення.

### Кнопки внизу

| Кнопка | Що робить |
|---|---|
| 📋 Мої пошуки | Список пошуків. Натисніть на пошук: 🔗 відкрити на сайті, ✏️ перейменувати, 🗑 видалити |
| 🔎 Перевірити зараз | Перевірити всі пошуки, не чекаючи 5 хвилин |
| 📊 Статистика | Скільки бот працює без перерви, коли була остання перевірка, скільки нових авто сьогодні / за 7 днів / по кожному пошуку |
| ⏸ Пауза / ▶️ Відновити | Тимчасово вимкнути сповіщення (наприклад, на ніч або у відпустці) |
| ❓ Допомога | Коротка інструкція |

Ті самі дії є в меню команд: `/list`, `/check`, `/stats`, `/pause`, `/resume`.

### Попередження від бота

| Повідомлення | Що означає | Що робити |
|---|---|---|
| ⚠️ Не вдається перевірити… немає з'єднання / сайт довго не відповідає / збій на боці сайту | Тимчасова проблема сайту або мережі | Нічого: бот продовжує пробувати і напише «✅ Знову перевіряються» |
| …сайт блокує запити (код 403/429) | Сайт обмежив часті запити | Зазвичай минає саме. Якщо повторюється, збільшити інтервал перевірки |
| …сторінку пошуку не знайдено (код 404) | Посилання застаріло | Видалити пошук і додати заново |
| …змінилась сторінка сайту. Потрібно оновити парсер | AUTO.RIA змінив сайт | Звернутися до розробника |

Бот попереджає тільки після 3 невдалих перевірок поспіль (~15 хв), щоб не
турбувати через випадкові збої, і лише один раз, без спаму.

Бот відповідає тільки власнику (`OWNER_CHAT_ID`). Іншим людям він пише «Це
приватний бот».

## Запуск: що потрібно від вас

Бот працює на сервері 24/7, сервер налаштовує розробник. Від вас потрібні
чотири речі, це близько 15 хвилин.

1. **Створити бота в Telegram.** Відкрийте [@BotFather](https://t.me/BotFather),
   надішліть `/newbot`, придумайте назву та ім'я бота (ім'я має закінчуватися
   на `bot`). BotFather видасть **токен**, довгий рядок на кшталт
   `123456789:AAH...`. Бот належить вам, а токен працює як пароль від нього.
2. **Передати токен безпечно.** Не пишіть токен відкритим текстом у чат.
   Надішліть його одноразовим посиланням, наприклад через Bitwarden Send або
   onetimesecret.com: таке посилання відкривається один раз і потім зникає.
3. **Надіслати свій chat id.** Напишіть боту [@userinfobot](https://t.me/userinfobot),
   він відповість числом `Id`. Це число не секретне, його можна надіслати
   звичайним повідомленням. Бот відповідатиме тільки цьому акаунту.
4. **Вибрати, де працюватиме бот:**
   - **Ваш сервер (рекомендовано).** Зареєструйтеся в хостингу, наприклад
     Hetzner Cloud, і створіть найменший сервер з Ubuntu 24.04. Він коштує
     близько €4–6 на місяць, оплата йде напряму хостингу. Під час створення
     додайте SSH-ключ розробника: розробник його надішле, це публічний ключ, а
     не пароль. Потім надішліть розробнику IP-адресу сервера. Пароль від
     акаунта хостингу нікому не передавайте.
   - **Сервер розробника.** Розробник розміщує бота в себе. Це окрема
     щомісячна плата за домовленістю. Тоді від вас потрібні тільки пункти 1–3.

Коли розробник повідомить, що бот запущено, відкрийте свого бота, натисніть
**Start** і додайте перший пошук (див. «Як користуватися»).

## Що робить розробник

- Налаштовує сервер: оновлює систему, створює окремого користувача для бота,
  вмикає брандмауер, у якому відкритий тільки SSH.
- Встановлює бота і вписує токен та chat id у файл налаштувань `.env` на
  сервері. Більше ніде токен не зберігається.
- Запускає автотести на сервері й вмикає службу автозапуску: бот сам
  перезапускається при збої та після перезавантаження сервера.
- Перевіряє, що бот відповідає вам і надсилає перші сповіщення.
- Після приймання роботи видаляє свій доступ до сервера або залишає його для
  підтримки, якщо ви так домовилися.

Сервер повністю ваш: доступ через панель хостингу завжди залишається у вас.

| | |
|---|---|
| Входить у замовлення | Разове налаштування бота на вашому сервері і перевірка, що все працює |
| Окремо, за домовленістю | Оренда сервера (платите напряму хостингу); розміщення на сервері розробника; підтримка після здачі (наприклад, оновлення бота, якщо AUTO.RIA змінить сайт) |

## Технічна інструкція

Цей розділ для розробника або того, хто обслуговуватиме бота.

### Встановлення

Потрібно: Python 3.11+ і сервер або комп'ютер, що працює постійно (Linux,
Windows чи macOS).

1. Отримайте токен бота від [@BotFather](https://t.me/BotFather) і chat id
   власника від [@userinfobot](https://t.me/userinfobot).
2. Встановіть бота:

   ```bash
   git clone <адреса репозиторію> autoria-bot
   cd autoria-bot
   python3 -m venv venv
   venv/bin/pip install -r requirements.txt
   cp .env.example .env
   ```

3. Впишіть токен і chat id у `.env`. Цей файл нікому не надсилайте: токен = пароль від бота.
4. Перевірте і запустіть:

   ```bash
   venv/bin/python -m pytest -q   # автотести, мають бути всі зелені
   venv/bin/python bot.py
   ```

5. Напишіть боту `/start`.

### Постійна робота на Linux-сервері (systemd)

Файл служби: `deploy/autoria-bot.service`. Він розрахований на користувача `bot`
і папку `/home/bot/autoria-bot`. Якщо у вас інші, замініть `User=`,
`WorkingDirectory=` і `ExecStart=`.

```bash
sudo cp deploy/autoria-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now autoria-bot   # запуск зараз і після перезавантаження
systemctl status autoria-bot              # чи працює
journalctl -u autoria-bot -f              # журнал наживо
```

Служба сама перезапускає бота, якщо він впав, і запускає його після
перезавантаження сервера.

Важливо: з одним токеном може працювати тільки **один** запущений бот. Перед
запуском на сервері зупиніть копію на комп'ютері.

### Оновлення

```bash
cd autoria-bot && git pull
venv/bin/pip install -r requirements.txt
venv/bin/python -m pytest -q
sudo systemctl restart autoria-bot
```

Пошуки і бачені оголошення зберігаються в `bot.db` і переживають оновлення та
перезапуск.

## Як це працює

```
autoria_parser.py  завантажує сторінку пошуку і дістає оголошення
storage.py         SQLite: пошуки, бачені оголошення, статистика, пауза
monitor.py         що нове + текст картки
bot.py             Telegram: кнопки, діалоги, перевірка за розкладом
```

- Дані беруться зі стану сторінки (`window.__PINIA__`), а не з верстки, тож зміна
  дизайну сайту бота не ламає. Береться тільки блок справжніх результатів, без
  реклами й «схожих пропозицій».
- Нове = ID, якого цей пошук ще не бачив. Підняте старе оголошення новим не
  вважається.
- Якщо бот довго не працював і на першій сторінці всі авто нові, він дочитує
  наступні сторінки (до 5), щоб нічого не пропустити.
- Якщо сторінка відкрилась, але оголошень 0, а сайт показує «N предложений»,
  це вважається поломкою, а не «нових немає». Бот попередить, а не мовчатиме.
- Між запитами паузи, щоб не навантажувати сайт.

## Обмеження

- Тільки AUTO.RIA. Інший сайт потребує свого модуля-парсера (решта бота не
  зміниться).
- Тільки Telegram. WhatsApp можливий через платний WhatsApp Business API
  (верифікація бізнесу, оплата за повідомлення).
- Бот читає публічні сторінки пошуку. Якщо AUTO.RIA серйозно змінить сайт,
  потрібно буде оновити парсер (бот про це попередить). Стабільніша, але платна
  альтернатива: офіційний API RIA (від ~$11/міс., деталі в `REPORT.md`).
